Get started

From download to dazzling in minutes.

  1. DownloadGrab ClassLibrary.dll using the button below and save it somewhere in your solution.
  2. Add a referenceIn Visual Studio: Project → Add Reference → Browse, then select the DLL. Your project should target .NET Framework 4.7.2 or later.
  3. Fill the ToolboxRight-click the Toolbox, choose Choose Items… and browse to the DLL. The controls appear under ZenForms Modern Controls.
  4. Apply the themeCall ZenTheme.Apply(this) in your form’s constructor to style the whole window in one line.
MainForm.cs
using ZenForms.Core;

public partial class MainForm : Form
{
    public MainForm()
    {
        InitializeComponent();
        ZenTheme.Apply(this);

        // A command palette in three lines
        var palette = new ZenCommandPalette();
        palette.AddCommand("Open project", "Ctrl+O", OpenProject);
        Controls.Add(palette);

        // Orbiting radial menu
        var orbit = new ZenOrbitMenu();
        orbit.ItemSelected += (s, e) => Text = e.Item;
        Controls.Add(orbit);
    }
}
